\# 🐹 薏米GPT (Yimi GPT)



> “用一点点算力，手搓一个属于自己的神经网络小模型。”



这是一个从零开始手搓的微型大语言模型（纯正 Transformer 架构）。

专为\*\*双核/无显卡的低配电脑\*\*打造，完整跑通了从\*\*网络爬虫 -> 数据清洗 -> 模型训练 -> 外挂聊天\*\*的全流程。



\## ✨ 核心特性 (Features)



\- 🧠 \*\*纯正架构\*\*：使用 `SwiGLU` 和 `RMSNorm`，参数约 100 万，纯 CPU 也能跑通。

\- 🕷️ \*\*残暴的爬虫清洗\*\*：自带多线程爬虫，支持黑名单过滤、中文占比校验，自动剔除网页广告。

\- 🛡️ \*\*大厂级防幻觉 (RAG)\*\*：内置权威知识库，如果神经网络打分极低（胡说八道），自动触发百度实时搜索兜底！

\- 🥚 \*\*极客隐藏彩蛋\*\*：代码底层隐藏了两个彩蛋，破解后可获得无限 Token 权限！



\## 🚀 快速开始 (Quick Start)



\### 1. 安装依赖

请确保你的 Python 版本在 3.8 以上：

```bash

pip install -r requirements.txt

```



2\. 开始训练你的模型



运行 

train.py

。程序会自动爬取数据、清洗、并开始无限训练（按 Ctrl+C 停止后，模型会自动保存到桌面）。



```bash

python 

train.py

```



3\. 唤醒你的 AI (Chat)



运行 

chat.py

。它会自动加载桌面上的模型文件，并启动计费与记忆系统。



```bash

python 

chat.py

```
